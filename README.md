# 🚐 Gurukrupa Travel – Customer Portal

A simple and user-friendly customer portal that allows customers to book travel services directly through a website and send their booking details via WhatsApp.

## ✨ Features

- 🌐 **Online Booking:** Customers can submit their booking details directly through the website.
- 📱 **WhatsApp Integration:** Send booking information through WhatsApp for quick communication.
- 📝 **Customer Details:** Collect essential customer and travel information.
- ⚡ **Simple Interface:** Easy-to-use booking experience.
- 📩 **Direct Communication:** Helps customers connect with the travel service provider without complicated booking steps.

## 🚀 How It Works

1. Open the customer portal website.
2. Enter the required customer and travel details.
3. Review the booking information.
4. Submit the booking through WhatsApp.
5. Confirm the booking directly with the service provider.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- WhatsApp integration

## 🎯 Purpose

To simplify the travel booking process by connecting customers directly with the service provider through a website and WhatsApp.

## ⚠️ Note

WhatsApp is used to communicate booking details. A booking should be considered confirmed only after confirmation from the service provider.
